# T0902 Result

Completed

## Scope delivered

- Added an account-scoped, bounded read-only catalog API and Material UI workspace for Woo products, variations, categories, source prices, stock state and stock quantity.
- Woo catalog synchronization now resolves numeric variation references through authenticated GET requests so variation price, SKU and stock facts are available without remote writes.
- Added a separate manual-order queue and a catalog-backed creation flow with required name, phone, address and configured Egyptian governorate shipping quote.
- Manual line identity and price are revalidated against the synchronized catalog on the server using integer minor units.
- Added private payment-proof upload/download for JPEG, PNG and PDF (5 MiB maximum), stored outside SQLite with random account/order-scoped paths, checksum verification and immutable one-proof association.
- Manual orders start as `awaiting-payment-proof` and can only become `confirmed` after the proof exists; they retain `syncPolicy=never` and `inventoryPolicy=ignore`.
