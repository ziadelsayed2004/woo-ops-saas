- Added reusable HTML PDF render-session exports to `@woo-ops/documents`.
- Added Arabic and English keys for the document file browser.

## Database indexes, migrations, environment or deployment changes

- No migration or new index is required.
- Deployments may override `WOO_OPS_ORDER_SYNC_INTERVAL_SECONDS`; valid values are 30-3600 seconds and the default is 60.

## Security, tenancy, money/time and idempotency review

- Active synchronization detection is scoped by authenticated `accountId` and connection ID.
- The order-only scheduler uses time-bucketed idempotency keys and refuses to overlap a queued or running automatic sync for the same account connection.
- Connectors remain read-only; money representation and immutable document snapshots are unchanged.
- Artifact downloads continue through the existing private, account-scoped API route.
