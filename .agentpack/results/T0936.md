# T0936 Result

## Outcome

- Repaired production document delivery: Chromium Headless Shell is resolved from the documents workspace during installation, and automatic generation falls back to the polished portable renderer only when the browser is unavailable.
- A batch with zero successful documents now fails explicitly instead of exposing a manifest-only ZIP as a useful result.
- Corrected mojibake in every Arabic HTML PDF label and the Arabic address separator.
- Added direct thermal-receipt and shipping-label print actions. The print window is reserved from the initiating click, loads the completed private PDF, opens the browser print dialog, preserves the selected orders, and leaves the durable command in history.
- Refined XLSX styling to the classic WooCommerce purple `#96588A`, a 24-point header row, and bounded widths of 26, 34, or 38 characters according to content type.
