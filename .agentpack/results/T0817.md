# T0817 Task Result

## Outcome

Hostinger shared-hosting installation is now targeted explicitly at Node 18.20.8. The native SQLite
dependency is pinned to `better-sqlite3` 8.2.0, whose Node 18 prebuilt installs without compiling via
the Hostinger-incompatible Python/node-gyp fallback. Vite and its React plugin were aligned with Node
18, deployment documentation and CI were updated, and the production smoke test asserts the locked
runtime contract before checking startup, migrations, health, backup and restore.

No Dockerfile, compose file, container build or Docker runtime dependency existed. Obsolete container
wording was removed. Two accidentally tracked SQLite WAL/SHM runtime files were removed; application
data, user environment files and fixtures were not deleted.
