# T0935 Result

## Outcome

- Production document generation now requires the branded HTML-to-PDF renderer instead of silently returning the legacy coordinate-based fallback.
- Chromium Headless Shell is installed into the deployed dependency tree during `npm install`, making the HTML renderer available in Hostinger release directories.
- A4 invoices, 80mm receipts and 80mm shipping labels use the supplied logo, WooCommerce-purple styling, Arabic RTL typography, complete order facts, item tables, totals, QR, barcode and support contacts.
- Operational and shipping XLSX presets now use Arabic worksheet/column names, RTL sheets, frozen branded headers and bounded readable widths.
- Existing profiles are versioned by both key and label, so installations receive the corrected Arabic columns rather than reusing an older English-label version.
