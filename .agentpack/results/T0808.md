## Security, tenancy, money/time and idempotency review

- All lifecycle and sync repository operations require authenticated account context; connection IDs, webhook ownership and sync runs are account/connection scoped.
- Woo connector methods are GET-only and expose no remote mutation escape hatch. Store URLs pass canonicalization, DNS and private-network SSRF checks.
- Credentials/webhook secrets use authenticated encryption; webhook signatures cover raw bytes and delivery keys are replay-safe. Failure categories and retry-after values are bounded and redacted.
- Sync checkpoints advance only after catalog/order/refund effects commit. Deterministic run keys, source identity upserts, overlap windows and reconciliation tokens make retries safe while preserving local workflow/export fields.
- Source timestamps remain available for cursoring; monetary data continues to use the existing integer minor-unit contracts.
