## Security, tenancy, money/time and idempotency review

- All manual reads/writes use authenticated account context and repository `account_id` predicates; assignee IDs must belong to the same account.
- Write routes require owner/admin/operator authorization plus CSRF/origin checks. Request payloads are Zod validated and repository validation remains defense in depth.
- Connector methods are never called. Manual orders have no connection or external identity and cannot enter remote sync.
- Totals use integer minor-unit strings and `BigInt`; no floating-point calculation was introduced. Timestamps are generated as UTC ISO strings.
- Updates use an optimistic version and append note history. Export/document edits retain immutable prior evidence and set a stale marker.
- JSON payloads, line counts, text lengths, tags, amounts and assignee scope are bounded.
