## Scope delivered

- Order and shipping Excel presets replace first/last name columns with one `الاسم بالكامل`
  column. The standard preset uses `woo.billingFullName`; dispatch uses `woo.shippingFullName`.
  Both Woo and manual order tabs share these presets.
- Full-name values join only their corresponding address's string name parts, trim/normalize
  whitespace and omit missing parts. Entire names already stored in first_name are retained.
  Missing names remain blank; other addresses are not mixed into the recipient name.
- The new column uses existing light-gray headers, RTL sheets and text formatting, with bounded
  width and wrapping for long names. Spreadsheet injection protection remains applied after joining.
- Existing profile-version matching automatically creates a new immutable version for changed
  columns. Legacy split-name mappings and historical export files remain unchanged.
