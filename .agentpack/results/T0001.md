- API does not accept an account/tenant authority in the current foundation endpoints.
- Money is represented as minor-unit strings in the domain contract.
- Jobs include an idempotency key in the application contract and a unique SQLite constraint.
- Full auth, account authorization and production encryption are intentionally follow-up tasks T0101-T0103.
