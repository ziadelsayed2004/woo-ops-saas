## Database indexes, migrations, environment or deployment changes

- Migration 15 adds membership lifecycle columns and indexes, `password_reset_tokens`, and
  `account_invitations` with account/status, token lookup, expiry and pending-email indexes.
- The migration is forward-only and preserves existing memberships with `status='active'` and
  `updated_at=created_at`; rollback is a forward-fix/backup restore operation because SQLite
  column/table removal would risk account security history.
- No credentials, external services, or production hosting state were changed.

## Security, tenancy, money/time and idempotency review

- No connector interface or Woo remote mutation was added. `exported` and membership/session
  lifecycle remain local workflow data.
- Account IDs come from `AuthService.current` and are revalidated by persistence membership
  checks; invitation acceptance binds the one-time token to the authenticated user's email.
- Passwords use the existing scrypt implementation; sessions and reset/invitation tokens are
  opaque and stored only as SHA-256 digests. Raw reset tokens are available only to an explicit
  delivery callback used by a future mail adapter, never from the HTTP response or logs.
- Dates are persisted as UTC ISO strings; no floating-point money path was introduced.
- Audits contain action/target/correlation metadata and no credentials, tokens, passwords or raw
  request bodies.
